# Signal Management 使用手册

## 1. 概述

Signal Management 是一个 CAN 总线报文信号定义工具。你可以在可视化的位网格画布上定义报文帧中每个信号的名称、位置、物理转换规则，并利用信号组管理重复结构，通过版本控制追踪每次变更。

### 核心概念

| 概念 | 说明 |
|------|------|
| **Message（报文帧）** | 一个 CAN 帧，由 1–64 字节组成，包含若干信号 |
| **Signal（信号）** | 报文帧中的一个命名位域，定义了原始值到物理值的转换规则 |
| **Signal Group（信号组）** | 一组信号的逻辑分区，在画布上以虚线框标记，支持表示循环体 |
| **Tag（标签）** | 可附加在信号或报文上的分类标记，用于筛选和组织 |
| **Version（版本）** | 报文信号的快照记录，支持回滚到任意历史状态 |

### 界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部导航栏：报文切换 / 名称编辑 / 导入导出 / 标签管理         │
├──────────┬──────────────────────────────────┬────────────────┤
│ 左侧边栏  │          中央画布                │   右侧面板     │

├──────────┴──────────────────────────────────┴────────────────┤
│ 状态栏：鼠标位置 / 信号信息 / 选区范围                        │
└──────────────────────────────────────────────────────────────┘
```

## 2. 创建与管理报文

### 创建报文

1. 点击顶部导航栏的 **+ New Message** 按钮
2. 填写报文名称（如 `CAN_MSG_01`）
3. 设置帧大小（1–64 字节，默认 8 字节）
4. 点击 **Create** 创建

### 切换报文

使用导航栏左侧的下拉菜单，在不同报文之间切换。

### 编辑报文属性

报文打开后，可以直接在导航栏中编辑：

- **名称**：直接点击名称输入框修改，回车或失焦保存
- **帧大小**：点击 Size 旁的数字修改，支持 1–64 字节
- **标签**：在 TagInput 区域添加或移除标签

### 删除报文

点击导航栏的 **Delete** 按钮，确认后删除该报文及其所有信号。

## 3. 信号定义

### 通过画布拖拽创建

1. 在中央的 Bit Canvas 上，按住鼠标左键拖拽，选择一段连续的 bit 区域
2. 松开鼠标，自动弹出信号定义表单
3. 选区范围显示在画布下方的状态栏中

### 通过按钮创建

点击左侧边栏的 **+ Add** 按钮，从起始位 0 开始创建一个新信号，之后在表单中调整位置。

### 信号属性

| 字段 | 说明 | 示例 |
|------|------|------|
| **Name** | 信号名称（必填） | `EngineRPM` |
| **Position** | 起始位和位长度，支持两种输入模式 | 见下方说明 |
| **Data Type** | 数据类型，选择后自动设置对应位长度 | `uint16` → 16 bit |
| **Byte Order** | 字节序 | Big-Endian / Little-Endian |
| **Factor** | 物理转换系数（默认 1.0） | `0.25` |
| **Offset** | 物理转换偏移（默认 0.0） | `-40` |
| **Unit** | 物理单位 | `rpm`、`km/h`、`%` |
| **Tags** | 标签（支持搜索和内联创建） | 见标签章节 |
| **Color** | 信号在画布上的显示颜色 | 16 种预设色 |

#### 物理转换公式

```
物理值 = 原始值 × Factor + Offset
```

例如：温度信号 Factor=0.5, Offset=-40，原始值 100 → 物理值 10°C。

#### 位置输入模式

- **Absolute（绝对位编号）**：直接输入 bit 编号（0 起始）
- **Byte:Bit（字节:位）**：分别输入起始字节和字节内的位号（0–7）

点击 Position 旁的 **Absolute** / **Byte:Bit** 按钮切换。

#### 数据类型

选择 Data Type 后，Bit Length 会自动设置为对应长度：

| 数据类型 | 位数 | 数据类型 | 位数 |
|---------|------|---------|------|
| uint8 | 8 | int8 | 8 |
| uint16 | 16 | int16 | 16 |
| uint32 | 32 | int32 | 32 |
| uint64 | 64 | int64 | 64 |
| float32 | 32 | float64 | 64 |
| boolean | 1 | | |

### 编辑信号

在左侧信号列表中，将鼠标悬停到目标信号上，点击编辑图标（铅笔），在弹出的表单中修改属性。

### 删除信号

在信号列表中悬停到目标信号，点击删除图标（垃圾桶），确认后删除。

## 4. 信号组

信号组用于将多个信号组织成一个逻辑单元，在画布上以虚线边界框标记。

### 创建信号组

1. 点击左侧边栏的 **+ Group** 按钮（紫色）
2. 填写组属性：
   - **Name**：组名称（如 `WheelData`）
   - **Description**：可选描述
   - **Start Bit**：组在帧中的绝对起始位
   - **Bit Width**：组占据的位宽度
   - **Repeat Count**：重复次数（留空表示不重复）
   - **Color**：组边界和背景的颜色
3. 点击 **Create Group**

### 重复组（Repeat Count）

当信号表示多路复用的循环数据时，设置 Repeat Count 表示循环次数：

- 留空：单个组，不重复
- 输入数字（如 4）：表示该结构重复 4 次
- 画布上会在组边界右上角显示 **x4** 标记
- 信号使用绝对坐标，只需定义第一个周期的布局，后续周期由渲染器推算

### 组内创建信号

在画布上的组区域（虚线框内）拖拽选区时，信号会自动关联到该组。信号列表中，组内信号以缩进形式显示在组标题下方。

### 编辑/删除组

- **编辑**：在信号列表中悬停到组标题，点击编辑图标
- **删除**：悬停到组标题，点击删除图标。删除组会同时删除所有成员信号。

### 折叠/展开

点击组标题左侧的箭头按钮（▶ / ▼），折叠或展开成员信号列表。

## 5. Bit Canvas 画布

画布以网格形式展示整个报文帧，每格代表 1 bit。

### 交互方式

| 操作 | 效果 |
|------|------|
| **拖拽选区** | 按住鼠标拖拽，选择一段连续 bit 区域，松开后创建信号 |
| **悬停信号** | 显示 tooltip：信号名、位置、数据类型、单位、物理转换参数 |
| **悬停空白** | 显示当前 bit 坐标（字节:位） |
| **悬停组区域** | 显示组名 |
| **点击信号** | 选中该信号，画布上高亮显示 |

### Bit 编号

画布上方提供 **MSB0** / **LSB0** 切换按钮，改变 bit 编号的显示方式：

- **MSB0**：最高位编号为 0（Motorola 位序）
- **LSB0**：最低位编号为 0（Intel 位序）

### 视觉标记

- 信号以彩色矩形显示在对应的 bit 格子中
- 不同信号使用不同的纹理填充以区分相邻信号
- 信号名称显示在信号区域顶部（名称过长时截断）
- 信号组以虚线边框标记，组内空闲 bit 有淡色底色
- 拖拽选区以蓝色边框预览

### 状态栏

画布下方显示上下文信息：

- 拖拽中：显示选区范围和 bit 数
- 悬停信号：显示信号名、位长度、数据类型、单位
- 悬停组：显示组名
- 悬停空白：显示字节和 bit 坐标
- 默认：提示 "Click and drag to select a bit region for a new signal"

---

## 6. 信号列表

左侧边栏按以下顺序显示所有信号：

1. **未分组信号**：直接列在顶部
2. **信号组**：每个组以可折叠区域显示，组标题带彩色左边框

### 信号行信息

每个信号行显示：

- 颜色标记（左色块）
- 信号名称
- 位置范围（如 `B0:0 — B0:7 (8b)`）
- 单位（如有）
- 标签（如有，显示前 3 个）

### 标签筛选

信号列表上方有一个标签筛选区域：

- 点击标签：筛选包含该标签的信号
- 再次点击：取消筛选
- 未分组信号和组内信号分别应用筛选

## 7. 标签系统

标签用于分类和筛选信号与报文。

### 标签管理页

点击顶部导航栏的 **Tags** 按钮进入标签管理页：

1. **创建标签**：点击左侧 **+ New**，输入名称并选择颜色
2. **查看标签**：点击左侧标签列表中的任意标签，右侧显示关联的报文和信号
3. **编辑标签**：悬停标签行点击编辑图标，或在详情页点击 Edit
4. **删除标签**：点击 Delete，确认后删除标签并从所有信号/报文中移除

### 内联创建标签

在信号表单或报文编辑器的 TagInput 区域：

1. 输入标签名称
2. 如果标签已存在：从下拉列表中选择
3. 如果标签不存在：下拉列表底部显示 "Create 'xxx'"，点击即可创建

按 **Enter** 键可以快速选择第一个匹配项或创建新标签。

### 颜色选择

标签提供 12 种预设颜色。创建时自动分配，也可以手动选择。

## 8. 版本管理

右侧 Version History 面板提供版本快照功能。

### 保存版本

1. 在右侧面板顶部的输入框中输入 commit message（如 "添加发动机转速信号"）
2. 按 **Enter** 或点击 **Save** 按钮
3. 当前报文的所有信号、信号组、标签状态将被保存为一个版本快照

### 查看版本历史

- 版本按时间倒序排列（最新的在最上面）
- 最新版本标记 **latest** 标签，以绿色背景高亮
- 每个版本显示 commit message 和保存时间

### 回滚版本

1. 找到目标版本
2. 点击 **Rollback** 按钮
3. 确认回滚操作
4. 系统会将报文恢复到该版本的状态，同时创建一个新的版本记录（保留回滚前的状态）

> 回滚不会丢失数据——回滚前的状态会被保存为一个新的版本快照。

## 9. 导入与导出

### 导出

点击导航栏的 **Export** 按钮，将当前报文导出为 JSON 文件。文件包含：

- 报文元信息（名称、帧大小、字节序）
- 所有信号组（名称、位置、位宽度、重复次数）
- 所有信号（名称、位置、物理转换参数、颜色、所属组名）

### 导入

1. 点击导航栏的 **Import** 按钮
2. 选择一个 JSON 规格文件
3. 系统自动创建报文、信号组和信号
4. 导入完成后自动打开新创建的报文

### JSON 文件格式

```json
{
  "version": 2,
  "message": {
    "name": "CAN_MSG_01",
    "frameSize": 8,
    "byteOrder": "big"
  },
  "signalGroups": [
    {
      "name": "DataBlock",
      "startBit": 8,
      "bitWidth": 16,
      "isRepeating": false,
      "color": "#8B5CF6"
    }
  ],
  "signals": [
    {
      "name": "EngineRPM",
      "startBit": 0,
      "bitLength": 16,
      "factor": 0.25,
      "unit": "rpm",
      "dataType": "uint16",
      "color": "#2563EB",
      "groupName": null
    },
    {
      "name": "Temp",
      "startBit": 8,
      "bitLength": 8,
      "factor": 0.5,
      "offset": -40,
      "unit": "C",
      "groupName": "DataBlock"
    }
  ]
}
```

信号通过 `groupName` 字段关联到对应的信号组（匹配组的 `name`）。`groupName` 为 `null` 表示该信号不属于任何组。
