# Scenario 3: Frame boundary with repeatCount

## Setup
Message: frameSize=4, bitLength=32 (max valid bit: 31)

## Command
curl -X POST http://localhost:3000/api/messages/41b8a546-700e-4997-add7-e120d64d892d/groups \
  -H "Content-Type: application/json" \
  -d '{"name":"Overflow","startBit":16,"bitWidth":8,"repeatCount":3,"color":"#FF0000"}'

## Calculation
startBit=16, bitWidth=8, repeatCount=3
effectiveEndBit = 16 + 8*3 = 40
frameSize*8 = 4*8 = 32
40 > 32 => Exceeds frame size

## Response
{"error":"Group region exceeds frame size"}
HTTP_STATUS:400

## Result: PASS
Correctly rejected with 400 Bad Request
